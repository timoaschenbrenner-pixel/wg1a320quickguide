# MUC WG1 A320FAM QUICK GUIDE

Line-Schnellübersicht für Fluggerätmechaniker (A318/A319/A320/A321 CFM56-5).

**Training only. AMM / TSM / CBL / SRM des MSN führen.**

## Module

- ATA Systeme + LTT A3 Schematics
- Belly Fairing Access + Stations/Frames/Stringer
- Antennen / Probes / Sensoren / Lichter
- Circuit Breakers
- Quick Reset

## Lokal starten

```bash
npm install
npm run dev
```

Dann im Browser die Dev-URL des Scripts (Default-Port laut `package.json`).

`npm run build` erzeugt den Production-Build.

## Hinweis

AMM-Tafeln in `public/` sind Auszüge aus Training-Unterlagen. Nicht öffentlich verteilen. Repo privat halten.
